# 10RemoteHub 桌面界面定义

这份文档定义界面“长什么样、每个状态怎么表现”。状态与规则在哪一层、数据怎么流动见 [ARCHITECTURE.md](ARCHITECTURE.md)。

交互参考 Logitech G HUB 的设备分配方式：在实物照片上点键、在侧栏分配。参考：[G HUB 官方界面说明](https://www.logitechg.com/en-ca/software/guides/g-hub-basics)。只借鉴交互方式，不借用品牌或视觉。

## 原则

1. 照片是主角。用户自己的遥控器照片（迁移的配套遥控器用内置示意图）放在浅灰工作台上，界面其余部分退后。
2. 一个强调色。蓝色 `ACCENT` 只表示“选中 / 已分配 / 主操作”，不给装饰用。
3. 完整即保存。按键、应用和语音设置在值完整时自动保存；自由文本通过「保存文本」明确提交，避免编辑中的半句话生效。文本有未保存修改时明确标记，切键或换动作前可保存、放弃或取消；已保存的清除和覆盖提供一次撤销。
4. 编辑不触发电脑操作。选键、分配、预览都不执行动作；设备接入后，按实体键才执行。迁移的配套遥控器不显示测试倒计时或学习工具。
5. 状态不只靠颜色。每个状态胶囊都有文字；不能设置的键同时用虚线和“不能设置”文字表示。

## 两类遥控器

- **照片学键的遥控器**：`0.3.0` 起新添加的遥控器都是这一类，包括新添加的 `0416:0602`。画布用用户导入并裁剪的照片，键位和键名来自学键；检查器保留「测试」和「名称与位置」，侧栏与「我的遥控器」提供「学习更多按键」。
- **迁移的配套遥控器**：从 `0.2.0` 升级时自动迁移的 `0416:0602` 配置（`model_id=usb-0416-0602`）。使用内置示意图和已核对的键表（见 [KEYMAP.md](KEYMAP.md)），不显示学习、测试、名称位置和照片编辑入口。下文的「迁移的配套遥控器」专指这一类。

## 设计令牌

全部定义在 `remotehub/theme.py` 的 `TOKENS`，QSS 由令牌生成。界面代码不写十六进制颜色。

| 用途 | 令牌 | 值 |
|---|---|---|
| 工作台 / 侧栏 / 卡片 | `WINDOW` / `SIDEBAR` / `PANEL` | `#F2F3F7` / `#E9EAEF` / `#FFFFFF` |
| 只读、悬停底 / 按下 | `SUNKEN` / `PRESSED` | `#F7F8FA` / `#E4E6EC` |
| 细线 / 控件边 / 悬停边 | `LINE` / `LINE_STRONG` / `LINE_HOVER` | `#E1E3EA` / `#D8DAE1` / `#C6C9D2` |
| 正文 / 次级 / 三级 | `INK` / `MUTED` / `FAINT` | `#1C1C1E` / `#626268` / `#A8A8AE` |
| 强调 | `ACCENT` / `ACCENT_DEEP` / `ACCENT_SOFT` / `ACCENT_EDGE` | `#0A84FF` / `#0066CC` / `#E6F1FF` / `#B5D6FF` |
| 成功 / 进行中 / 错误 | `GOOD` / `WARN` / `BAD`（各有 `_SOFT` 底） | `#1E7E34` / `#B25000` / `#D70015` |

- 字体：macOS 系统字体 + PingFang SC；Windows Segoe UI + Microsoft YaHei；Linux Noto Sans (CJK)。页面标题 24 px 粗体，检查器标题 17 px，分区 13 px 半粗，正文 13 px；辅助说明 12 px、使用 MUTED 保持可读性，FAINT 只用于禁用和占位文字。
- 间距只用 4 / 8 / 12 / 16 / 24；圆角：控件 7、列表行 8、卡片 14。
- 焦点：所有可聚焦控件都有 2 px `ACCENT` 焦点框。

## 窗口骨架

默认 1280×840，最小 1200×720（此时检查器与画布都不被裁切，无横向滚动）。

- 侧栏固定 220 px：品牌、四个页面导航、遥控器卡片；按键映射页另显示配置方案与按键导入导出。
- 工作区：标题与副标题、页面内容、底部反馈条。插入了内置型号的接收器、但还没有遥控器接受它时，标题下方显示「添加这只遥控器 / 忽略」横幅。映射页左侧为可伸缩画布，右侧 320 px 检查器独立纵向滚动。
- 四页依次为我的遥控器、按键映射、语音设置、通用设置，快捷键 Ctrl/⌘+1–4。按键接入自动开始，没有启用映射开关。

## 侧栏

遥控器卡片：已添加多只遥控器时显示选择框，只有一只时显示名称（新遥控器默认按硬件 ID 命名，如「遥控器 0416:0602」，可在「我的遥控器」重命名）。下面依次是状态胶囊、说明、「前往通用设置」、还有未完成项时的「完成设置（还差 N 项）」、「添加遥控器」（我的遥控器页不重复显示）与「重新检测」，以及照片学键的遥控器才有的「学习更多按键」。不显示序列号或固件宣传名称。

配置方案只在按键映射页显示：单方案显示名称和「重命名…」，多方案才显示选择框和「管理…」，「新建…」始终可用。导入按键配置时可替换当前配置或保留为新配置；新配置自动区分同名，可重命名和删除。导出只包含图片与按键动作，不包含语音设置。

| 状态 | 外观 |
|---|---|
| 检测中 / 未发现 / 型号未适配 | 灰底灰字 |
| 已识别，尚未接入 | 浅蓝底 |
| 正在接入 / 等待授权 | 浅橙底 |
| 按键已接入 / 语音已接入 | 浅绿底 |
| 检测或接入失败 | 浅红底，附失败说明 |

连接失败时侧栏提供「前往通用设置」。未发现接收器提示检查 USB 接口；采集未就绪指向「通用设置 → 设备连接」，显示安装或重新检测路径；旧 HID 独占诊断与 USB 未插入分别呈现。通用设置保留可复制的原始错误，并说明开发版更新后旧授权可能失效。

普通启动自动扫描并尝试接入已添加遥控器的接收端。失败后保持提示，不循环请求；授权后点「重新检测」，或重新插入设备再尝试。USB 音频接管期间不重复打开独占监听。

## 我的遥控器页

「已添加」标题右侧是主操作「添加遥控器」。每只遥控器一张卡片：名称、接收端（可以有多个 USB 接收器或蓝牙连接）、按键数与连接状态；主操作「打开按键映射」，链接「学习更多按键」（照片学键的遥控器）、「重命名」「删除」。没有遥控器时提示插入接收器或连接蓝牙后点「添加遥控器」。下方「能接入哪些遥控器」卡片用大白话说明四档接入结果和麦克风能否使用。

## 添加遥控器窗口

1. **选设备与试按**：列出 App 看到的 USB 接收器和蓝牙设备。选中后按一颗键，结果分四档：✅ 直接接入、🔧 点一下就能接入、⚠️ 目前无法自动接入、❓ 看不到设备。🔧 档在窗口内给出对应的一键操作：Windows「让 App 接管这个接收器」（非 `0416:0602` 的设备 15 秒内要点「保留接管」，否则自动恢复）、蓝牙棒卡片的「切换为 BLE 直连模式」与「扫描 BLE 遥控器」、Mac 的输入监控授权入口。⚠️ 档列出「可以试试」的做法和「复制给 AI 的求助」。
2. **扫描 BLE 遥控器**：列表里已选中某只遥控器时只找这一只；没选中时只自动连接明确是遥控器的设备，「可能是」的设备只选中，等用户确认。
3. **照片学习**：「导入照片，开始学习」→ 拍摄建议 → 四角裁剪校正（或直接使用原图）→ 先问「这只遥控器物理上带有麦克风（语音键）吗」，有就先在照片上点语音键，并说明麦克风能否使用（直接能用 / 换蓝牙棒直连能用 / 目前用不了）→ 逐个点照片按键位置、两步选「分区 → 键位 / 自定义名称」（标准 HID 键支持直接按实体键自动识别）并按实体键学习，可在照片上改名、删键。
4. 保存后自动弹出「完成设置」。

## 完成设置清单

分「必须完成」和「可选」两组。每项一行：名称、状态、一句话说明和一个操作按钮，做完自动打勾。按平台和遥控器列出：

- macOS：读取组件（配套接收器）或输入监控权限（其他遥控器），以及辅助功能权限。
- Windows：让 App 接管接收器（配套接收器，可选）。
- Linux：设备权限（udev 规则）。
- 支持遥控器麦克风时：虚拟麦克风（可选）。Mac 运行中装好后按钮变为「重新打开 App」。

首次引导的第二步共用这份清单。

## 按键映射页

### 画布

- 照片学键的遥控器显示学过的键；标为语音键的那颗只设置语音，其余键可分配动作。
- 迁移的配套遥控器显示 30 个实体键：电源和 TV 永远是虚线框 + “· 不能设置”，不能点、不能选；28 个 USB 按键中语音键只设置语音，其余 27 键可分配动作，映射计数分母为 27。
- 每个键一根引线和一个标签：
  - 引线从热区外侧边缘水平引出，到照片外 18 px 的拐点，再斜向标签。同一行的键错开 4 px，同侧标签按键的行序排列，因此引线互不交叉。
  - 中间一列的键（2/5/8/0、上下、语音、主页、M 等）按附近行的标签密度分到较空的一侧，左右两列大致平衡。
  - 标签宽度按粗体计算，选中变粗也不会被截断；放不下时省略号截断并在提示里给全文。
- 标签三态：未分配只显示键名（灰字白底）；已分配显示“键名  动作”（浅蓝底、蓝边）；选中为蓝底白字。
- 热区：已分配为蓝边淡蓝填充，选中再加外光晕，悬停有浅色描边，未分配为淡灰描边。
- 交互：单击热区、标签或引线选中；双击或 Enter 跳到检查器的编辑控件；方向键按顺序切换可配置键；Tab 依次聚焦标签。
- 照片学键的遥控器在检查器「名称与位置」里编辑；打开「在图上框选位置」后画布上方显示框选横幅，拖出新位置松手即保存。迁移的配套遥控器没有这些入口。

### 检查器

普通键从上到下：

1. “单击 / 双击 / 长按”手势切换，明确当前编辑的手势，以及键名与“单击动作：…”摘要；文本草稿显示“未保存，原动作保留：…”。语音键只允许单击。
2. 当前手势动作需要的参数编辑器；按实际页面高度布局，不给隐藏的文本页预留空白，不需要参数时不占位。
3. 灰色说明与「清除单击/双击/长按映射」入口；只清除当前手势，底部可撤销一次。快捷键旁不再重复提供含糊的“清空”。
4. 标题“选择当前手势要执行的动作”下，平铺按键与应用、窗口、滚动与翻页、媒体、编辑、切换与浏览、系统七组动作。组名仅是标题，没有二级菜单；每组两列，选中项浅蓝底。

| 动作 | 参数与保存 |
|---|---|
| 按键 / 组合键 | 录制框；录制完成自动保存；非法组合显示错误 |
| 输入文本 | 多行纯文本框、明确标签与「保存文本」按钮；支持中文/英文/空白/换行，1–10000 字符；错误在字段旁显示，离开未保存草稿前询问 |
| 打开 / 收起 App | 选择应用后保存；未运行启动、后台显示、前台收起 |
| 打开文件 | 选择文件后保存；可指定打开方式或使用系统默认 |
| 显示所有应用并选择 | 位于「切换与浏览」；按一次显示全部应用，继续按选择下一个，停顿约 1 秒或确定打开，返回取消。保持与释放在内部完成，不提供额外的“按住/锁定修饰键”配置项 |
| 收起 / 关闭当前窗口、退出当前应用及常见操作 | 点击立即保存，无额外弹窗 |

macOS 选择 App 使用原生文件选择窗口并过滤 `*.app`，不能使用只选文件夹模式；应用包和文件打开方式共用此入口。Windows 与 Linux 优先弹出已安装应用列表对话框（Windows 自动扫描开始菜单 `.lnk` 并解析友好名称，Linux 自动扫描 XDG `.desktop` 应用目录），同时保留底部「浏览本地文件…」入口。

只展示当前系统支持的常见操作。旧配置 `app` 的只打开语义保留；新分配入口统一为打开 / 收起 App。已保存的清除和覆盖可撤销一次；写入失败保留原动作并反馈错误。

双击和长按是可选手势，未设置某手势表示没有为它分配电脑动作，不调用遥控器原厂功能。未配置双击/长按时单击仍在按下时立即执行；配置双击后单击等待 280 ms；配置长按后，550 ms 触发长按、短按在松开时执行。方向快捷键、滚动、翻页和音量增减允许连发，其他动作不连发。

照片学键的遥控器在检查器底部显示「测试」（倒计时后执行一次当前动作，语音动作不可测）和可展开的「名称与位置」：名称、实体按键、位置百分比、在图上框选位置、更换照片、移除这个键。编辑应用层或九键时隐藏「名称与位置」。迁移的配套遥控器不展示这两项。

### 快捷键显示

按宿主系统习惯：macOS 用符号且按 ⌃⌥⇧⌘ 排序（`⇧⌘4`），Windows/Linux 用 `Ctrl + Shift + A`，`cmd` 在 Windows 显示 Win、Linux 显示 Super。

实体语音键选中时，右侧替换为专用编辑器：麦克风来源、识别软件唤起键、按住/松开或按两次切换。新配置默认「未启用」，选择麦克风后才显示后续控件；已有明确选择保留，也可随时改回未启用。唤起键改为点击录制：按下单键或组合键、松开保存，支持单独 Alt/Option，不接受文本或输入法提交。隐藏普通动作列表及清除映射；「更多语音设置」进入语音页面。普通动作列表不再重复提供语音入口，旧其他按键的语音动作保留兼容。

## 语音设置页

五张编号卡片随右侧工作区宽度伸展，与页面标题和通用设置共享左右边界，不再限制 780 px。表单标签列统一为 96 px，左对齐，字段占用剩余宽度；不继承 macOS 默认居中表单布局：

1. 语音来源：未启用（默认）、遥控器麦克风，或仅触发识别（不读取电脑麦克风，识别软件继续使用当前麦克风）。同页下方提供音频组件准备与检测。
2. 遥控器操作：按住说话、松开结束，或按一次开始、再按一次结束。
3. 识别软件触发：识别快捷键及该快捷键的按住 / 切换方式，并显示遥控器操作与电脑快捷键的实际执行顺序。「不发送快捷键（手动控制识别软件）」只在来源为遥控器麦克风、且不是迁移的配套遥控器时提供。

4. 遥控器音频连接：自动连接本项目虚拟麦克风，显示就绪状态、虚拟麦克风安装/启动入口和语音增益；Mac 音频与按键共享采集，不另设音频连接/断开按钮；其他平台保留既有入口，不罗列扬声器。不显示解码、内部采集架构等实现信息。Mac 区分未安装、已安装尚未生效、已就绪；已安装但未被系统识别时提供「完成设置」，安装器自动加载并核对注册；仅激活失败才提示重启，重新检测给出明确结果。Mac 设备与虚拟麦克风就绪后自动连接音频；其他平台连接前检查配置和设备，满足条件才显示接管确认。
5. 音频检测：优先提示直接按住遥控器语音键并观察全宽实时电平条、相对百分比及当前等待原因；电平是只读指示，不是滑块。声音进入后随真实电平更新，空闲归零。虚拟麦克风未就绪时禁用 WAV 文件测试并解释原因；准备好后可使用高级 WAV 文件测试，录音/测试中可停止。音频连接和检测仅在来源为遥控器时出现。

字段自动保存；会话进行中不能更改来源、方式、快捷键、增益。非法输入保留原设置并显示错误。遥控器手势和外部软件快捷键方式是独立设置。

## 通用设置与状态栏

同样使用带细描边的白色卡片、随右侧工作区伸展、纵向滚动。窗口最小尺寸仍为 1200 × 720，保持映射页空间。卡片与内容列不得压缩到内容所需高度以下；多行错误变长或窗口变小时增加滚动范围，不裁切按钮或文字：

- 启动与后台运行：登录后自动启动，默认关闭；说明关闭窗口与退出程序的区别。
- 权限与设备连接：Mac 辅助功能与输入监控状态及前往授权；同一卡片展示统一读取组件安装、更新、卸载和设备状态，不另列按键/音频助手。按用户提供的参考图，已打包运行时点击授权后，在真实系统设置窗口的内容区底部显示白色圆角拖拽面板，保留系统加减按钮空间；上方说明、下方 App 图标与向上拖动提示，带关闭与访达/键盘替代入口。面板不抢焦点，跟随系统窗口，切换应用隐藏，拖放被接收/完成授权/关闭窗口/Escape/退出 App 时停止计时并收起；取消拖放保留面板，成功拖入不等同系统已授权；启动时不出现。只读窗口元数据定位，不复制系统授权列表或要求额外授权。通用设置不重复放置拖拽图标。启动只读预检读取组件，不自动安装；直接 USB 采集不再要求 GUI 输入监控。其他系统显示对应说明。
- 由 App 接管的接收器（Windows）：列出已接管的接收器，说明接管后只由 App 读取，提供「恢复系统驱动」。
- 交互层级：主要操作蓝色实底；安装、重新检测、前往授权、断开、文件测试等次级操作均有按钮边框及悬停/按下/键盘焦点反馈；输入字段有浅底和边框；状态为文本/胶囊，说明为次级文字。虚拟麦克风状态单行显示，按钮靠右，不挤压状态文字。

状态栏提供打开主窗口、通用设置、权限、停止语音与退出。无可用状态栏时保留窗口。界面不自动安装驱动、不改变系统默认麦克风。

## 反馈

- 底部反馈条只显示最近一条：成功为灰字，失败为红字。实体键按下先显示“已收到「键名」按键”，未配置时明确标注；动作保存后显示“「键名」→ 动作，已保存”。虚拟麦克风未就绪只提示语音设置，不用全局设备错误覆盖。瞬时 USB 读取中断显示正在重连。
- 照片学键的遥控器在框选模式下，画布上方显示「框选模式」横幅与「完成」；迁移的配套遥控器没有该入口。

## 屏幕浮层

九宫格、键位速查、方案切换提示条、九键输入和语音状态都是不抢焦点的浅色卡片：`PANEL` 底、`LINE_STRONG` 描边、圆角 16，与主窗口共用令牌。

- 九键输入：标题栏有蓝色点缀、标题和模式标签；3×3 键位显示数字与字母；当前键和选中候选为 `ACCENT` 底白字；精简候选条模式收缩高度，不留空白。
- 语音状态：状态圆点（录音时变红）、状态文字和电平条。

## 图片与图标

迁移的配套遥控器使用 `remotehub/assets/remote-tv.png`。它由 `scripts/build_remote_illustration.py` 生成，是项目自己的示意插图（不再使用厂商/用户照片），按钮矩形与热区定义保持一致。热区按图定位，28 个键码由 Mac 原始报文核对，证据见 `assets/tv-keymap.json`。禁配标记由界面绘制，不修改原图。公开发布前需确认图片分发许可。照片学键的遥控器使用用户导入并裁剪的照片，保存在本机配置中。

应用图标：纯白底、倾斜 42° 的黑色遥控器与蓝色顶端点缀（用户选定 B 造型 + C 配色），SVG 构建时渲染为 PNG / ICNS / ICO；状态栏使用透明模板蒙版。见 `remotehub/assets/ICONS.md`。

语音页滚轮始终用于滚动页面；增益不响应滚轮，使用文本、加减按钮或键盘方向键编辑。语音来源/模式选择器关闭时不响应滚轮，展开后的选项列表仍可滚动。避免仅因鼠标经过字段就修改并自动保存配置。
