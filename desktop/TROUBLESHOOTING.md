# 10RemoteHub 排障指南

以下重点覆盖常见安装、通用 USB／蓝牙遥控器接入与系统权限问题；Windows 接管接收器、外接蓝牙棒直连、管理员窗口 UIPI 限制、语音与日志排查见 [Windows 安装说明](INSTALL-Windows.md) 与 [Windows 端说明](docs/WINDOWS-TESTING.md)；Linux `udev` 最小权限规则、Wayland `/dev/uinput` 与 PipeWire/PulseAudio 虚拟麦克风排查见 [Linux 安装说明](INSTALL-Linux.md)。请从 [GitHub Releases](https://github.com/yizhixiaoheigou/10RemoteHub/releases) 获取正式发布包并核对校验清单，旧开发包不代表该版本。

菜单栏 / 托盘图标是灰的，说明当前启用的遥控器还没有连上；打开「通用设置」看「遥控器与读取组件」（Mac）或「设备连接」（Windows）下的连接状态，以及「我的遥控器」页面卡片状态。

## 通用遥控器在列表中看不到，或「添加遥控器」试按无信号

1. **Mac「输入监控」权限**：通用 USB / 蓝牙 HID 遥控器及「添加遥控器」试按必须授予**「输入监控」**权限。到「通用设置 → 系统授权 → 输入监控 → 前往授权」打开开关后，点「重新检测」。
2. **只在需要时接管或装组件**：通用 HID 遥控器不需要 Mac 读取组件，也不需要在 Windows 上让 App 接管。添加窗口显示「✅ 直接接入」时直接学键即可；显示「🔧 点一下就能接入」时再按提示操作。
3. **设备类型边界**：系统已连接但仍不出现在列表时，在「添加遥控器」窗口点「没检测到我的接收器 / 蓝牙设备？」，选择该设备即可看到它属于哪一档以及「可以试试」的做法；点「复制给 AI 的求助」可获取脱敏诊断，继续排查。
4. **Windows 上 `0416:0602` 学不到 `#` 号键**：先在添加窗口点「让 App 接管这个接收器」并重插接收器（不接管时 Windows 自己会吞掉 `#` 键），再回来学键。
5. **Windows 蓝牙遥控器显示「自带蓝牙无法读取，需要外接蓝牙棒」**：Windows 的蓝牙驱动拒绝读取这只遥控器（设备管理器报错误代码 10）。插一只外接 USB 蓝牙棒，按 [Windows 安装说明](INSTALL-Windows.md) 的「外接 USB 蓝牙棒」一节切换为直连模式。

## 安装时被 macOS 拦下

**现象**：双击后提示「无法验证开发者」「Apple 无法验证此 App 是否包含恶意软件」，或提示「已损坏，无法打开」。

前两种是正常的：本软件用项目自制的签名证书，没有购买 Apple 开发者证书。

1. 打开「系统设置 → 隐私与安全性」，滚动到「安全性」区域，点 10RemoteHub 旁边的「仍要打开」，输入开机密码；
2. 再双击一次应用，在弹窗里点「打开」。

如果是「已损坏，无法打开」，还可能涉及文件损坏、改动或签名问题，不能直接认定为隔离标记。先从正式发布来源重新下载，核对该版本提供的 SHA-256；仍失败时提供完整提示、版本和校验结果。不要直接移除隔离标记或关闭 Gatekeeper 来掩盖原因。系统提示的区别见 [Apple 官方说明](https://support.apple.com/en-au/102445)。

## 打开后找不到窗口

本应用常驻菜单栏，关掉窗口不等于退出。

- 单击菜单栏图标，选「打开主界面…」；
- 或单击 Dock 里的 10RemoteHub 图标。

## 按键没有反应

按顺序检查，四步之内基本能定位：

1. **辅助功能权限**：「通用设置 → 系统授权」里「辅助功能」是否为「已授权」。未授权时点「前往授权」，主窗口会自动最小化，把引导面板里的图标拖进系统设置列表，再打开开关。
2. **设备连接前置组件**：侧栏出现「完成设置（还差 N 项）」时，先点开把必须完成的项目做完。若使用配套 `0416:0602`，确认「通用设置 → 遥控器与读取组件」（Mac）或「设备连接」（Windows）为「已连接」（Mac 安装读取组件；Windows 让 App 接管接收器）；若使用其他 USB / 蓝牙 HID 遥控器，确认「输入监控」已授权且接收器/蓝牙已连接。
3. **接收器**：确认接收器插在电脑上，或系统蓝牙设置显示「已连接」，换一个 USB 口再试。
4. **这个键的动作**：打开映射页确认该键已绑定实体键码并分配了动作，没有被清空。有遥控器麦克风的语音键（配套 `0416:0602`，或照片上标为语音且命中内置语音协议的键）固定用于语音，不参与普通按键映射。

四步都对还是没反应，带上日志来问（见文末）。

## Mac 上遥控器闲置很久后普通键没反应，按一下语音键又好了

旧版读取组件只在开始读取时向接收器发一次同步指令；遥控器休眠醒来后，接收器可能不再转发普通键，直到按语音键重新同步。`0.3.0` 的读取组件在空闲时每 10 秒补发一次同步。

更新 App 后，**需要重新安装一次读取组件**才会生效（App 不会自动替换已装的组件）：打开 `/Applications/10RemoteHub.app/Contents/Resources/components/RemoteHubDevice.pkg`，按提示输入密码即可，虚拟麦克风和权限不受影响。

## 系统设置的权限列表里出现两个 10RemoteHub

旧版本用另一张证书签名，系统会当成两个应用。

删掉旧的那一条（通常没有开关或开关打不开），保留当前在用的、开关已打开的那条，然后回应用点「重新检测」。

## 按键重复触发，或按住后不松开

旧版本的采集程序在 USB 超时时会丢掉松开报文，表现为“按一下触发两次”或“一直处于按下状态”。新版已改为保留超时里实际收到的数据、所有端点并行异步读取。

更新到最新版即可。仍出现时，按文末方式提供日志。

## 语音说完没有出字

先判断是哪一段断了：

1. **识别软件在等吗**：按下语音键时，识别软件有没有进入“正在听”的状态。没有的话，是唤起键不对——到「语音设置」里重新录制识别软件的开始/结束快捷键。
2. **麦克风选对了吗**：
   - 自动切换模式：识别软件里选「系统默认」或「跟随系统」；
   - 固定模式：识别软件里选「10RemoteHub Microphone」。
3. **系统里有这个麦克风吗**：打开「系统设置 → 声音 → 输入」，看有没有 10RemoteHub Microphone。没有的话，到「语音设置 → 虚拟麦克风」重新安装（声音会中断一两秒）。
4. **电平有反应吗**：「语音设置」里的电平检测条，按住语音键说话时应该在动。不动说明音频没进来，回到第 3 步。

## 装完虚拟麦克风，声音或录音中断了

正常现象。安装器会重启系统音频服务，声音和录音会中断一两秒。先暂停通话或录音再安装。

## 装完虚拟麦克风，「重新检测」还是看不到

App 运行时装的虚拟麦克风，要重新打开 App 才能看到：系统音频服务重启后，已经在运行的程序拿不到新的设备列表。语音设置会显示「已安装，重新打开 App 后生效」，点「重新打开 App」即可。

## Windows 上扫描蓝牙遥控器连到了别的设备

先在添加窗口上方选中你的遥控器，再点「扫描 BLE 遥控器」，扫描就只找这一只，附近的耳机、相机等不会被连接。没有选中时，App 只自动连接明确是遥控器的设备，「可能是」的设备会列出来等你确认；连上后发现没有按键服务的设备会被移除。

## Windows 上蓝牙遥控器的语音不是边说边出字

`0.3.0` 起，语音期间 App 会让蓝牙连接保持在 7.5–15 ms 的通信间隔，声音实时送达。仍感觉慢时，打开 `%LOCALAPPDATA%\RemoteHub\ble-dongle\session.log`，看每次说话后的 `voice finished` 一行：`delivered` 与 `audio` 接近、`after_release` 接近 0，说明蓝牙这段已经实时，延迟在虚拟声卡或识别软件一侧。

## 电平一直是 0

- 虚拟麦克风没装或没选对（见上一条）；
- 第一次使用时系统问了麦克风权限，选了「不允许」。到「系统设置 → 隐私与安全性 → 麦克风」里打开 10RemoteHub；
- 遥控器电量不足或离接收器太远。

## 想彻底卸载

用发布页提供的卸载程序（`10RemoteHub-<版本>-<构建号>-arm64-Uninstall.pkg`），它会：

- 退出前先确认应用已退出；
- 删除 `/Applications/10RemoteHub.app`；
- 卸载后台读取组件 `/Library/PrivilegedHelperTools/10RemoteHub`；
- 卸载虚拟麦克风 `/Library/Audio/Plug-Ins/HAL/RemoteHubAudio.driver` 并重载音频服务；
- 移除登录启动项和系统里的安装记录。

只删确认属于本项目的文件，其他内容保持原样。用户配置（按键映射、语音设置）默认保留在 `~/Library/Application Support/RemoteHub`，想连配置一起删可以自己删这个目录。

手动卸载的顺序（通常不需要）：先退出应用，再删上面三个路径，最后用 `launchctl bootout system/org.remotehub.device-helper` 卸掉后台服务。

## 反馈问题时请附上

- 系统版本（macOS 版本与芯片，或 Windows 版本）；
- 遥控器能不能在别的电脑上正常用；
- 日志文件：macOS `~/Library/Application Support/RemoteHub/logs/connection.log`；Windows `%LOCALAPPDATA%\RemoteHub\logs\connection.log`，蓝牙棒直连另附 `%LOCALAPPDATA%\RemoteHub\ble-dongle\session.log`。

日志只记录连接事件和错误类型，**不记录按键内容、音频和识别出的文字**。蓝牙棒直连日志会记下扫描到的附近蓝牙设备名称和地址，公开发送前可以把这些行删掉。
